# TechNova 2026 — NGFCET Event Portal (v2)

Single-file self-contained HTML5/CSS3/JS version built so that GitHub Pages and mobile browsers load all styles, gradients, dark mode, and interactive scripts without any relative-path issues.

## How to Deploy on GitHub Pages
1. Extract this ZIP file.
2. Upload `index.html` directly to the root of your GitHub repository.
3. Refresh your GitHub Pages URL (`https://username.github.io/repo-name/`).
